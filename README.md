## 🎯 Project Overview
A comprehensive Java Swing application demonstrating Object Oriented Programming principles through a fully-functional movie ticket booking system.

## 🚀 Features
- User Registration & Authentication
- Movie Selection & Seat Booking
- Real-time Seat Availability
- Dynamic Pricing
- Ticket Generation & Cancellation
- Admin Management Functions

## 🛠️ Technologies
- Java Swing
- Java AWT
- OOP Principles
- HashMap Data Structures

## 📁 Project Structure
- CineVerse.java # Main application
- LoginPanel.java # Authentication
- RegisterPanel.java # User registration
- MenuPanel.java # Booking interface
- TicketPanel.java # Ticket management
